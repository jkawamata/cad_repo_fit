# CADレポFIT

Tinkercadなどで作成したSTLファイルを読み込み、提出用の3MFファイルとCAD課題報告書を作成する、ブラウザだけで動くWebアプリです。

## できること

- STLファイル、またはCADレポFITで作成した3MFファイルを読み込む
- 立体を回転・移動・拡大縮小して、見栄えのよいパース図を選ぶ
- 平面図・正面図・右側面図を自動表示する
- 学年、クラス、番号、氏名を入力する
- 「参考にしたもの」「気づいたこと・考えたこと」を記入する
- レポートの表示を確認し、A4縦1枚で印刷する
- 立体データとレポート設定を提出用3MFとして保存する

## 使い方

1. `index.html` をWebブラウザで開きます。
2. 右側の **① 立体データを読み込む** を押すか、STLまたは3MFファイルを画面へドラッグ＆ドロップします。
3. **② 提出者情報の入力** で、学年・クラス・番号・氏名を入力します。
4. **③ レポートを作成** で、パース図の向きや大きさを調整し、文章を記入します。
5. **④ 提出用3MF保存** を押して、提出用ファイルを保存します。

Shiftキーを押しながら④を押すと、CAD課題報告書を印刷できます。

## 提出用3MFについて

保存した3MFには、立体データに加えて次のレポート設定がメタ情報として保存されます。

- パース図の拡大率・視点・位置
- 正投影図の拡大率
- 参考にしたもの
- 気づいたこと・考えたこと
- 報告書の作成日時

同じ3MFをCADレポFITで読み込むと、これらの設定を再現してレポート編集画面を開きます。

提出者の学年・クラス・番号・氏名は、提出用3MFのメタ情報には保存せず、ファイル名から復元します。

## ファイル名

提出用3MFは、次の形式で保存されます。

```text
学年クラス番号_YYYYMMDD_HHMM_氏名.3MF
```

例：

```text
1101_20260809_1530_川俣純.3MF
```
